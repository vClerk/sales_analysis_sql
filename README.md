## 📌 Project Overview

This project focuses on analyzing a **retail sales dataset using SQL** to extract meaningful business insights from transactional data.

The analysis covers:

- 📊 Overall sales performance
- 👥 Customer behavior
- 🛒 Product category performance
- 👨‍👩‍👧 Gender-wise purchasing patterns
- 📅 Monthly sales trends
- 💰 High-value transactions
- 🏆 Top customers
- ⏰ Sales activity by time of day

The main objective is to demonstrate how SQL can be used not only to retrieve data, but also to answer **real-world business questions and support data-driven decision-making**.

# 🔎 SQL Analysis

## 1️⃣ Overall Sales Volume

```sql
SELECT COUNT(*)
FROM sales_data;
```

**Result:** `1,987` transactions.

---

## 2️⃣ Unique Customers

```sql
SELECT COUNT(DISTINCT customer_id)
FROM sales_data;
```

**Result:** `155` unique customers.

---

## 3️⃣ Category-wise Sales Performance

```sql
SELECT 
    category,
    SUM(total_sale) AS net_sales,
    COUNT(*) AS total_sales
FROM sales_data
GROUP BY category;
```

This identifies:

- Total revenue generated by each category
- Number of transactions in each category

---

## 4️⃣ Customer Demographics

The project analyzes the average age of customers purchasing products from specific categories.

Example:

```sql
SELECT ROUND(AVG(age), 2)
FROM sales_data
WHERE category = 'Beauty';
```

This helps understand the demographic profile of customers for different product categories.

---

## 5️⃣ High-Value Transactions

```sql
SELECT *
FROM sales_data
WHERE total_sale >= 1000;
```

This identifies transactions generating **1,000 or more in sales**, helping analyze high-value purchases.

---

## 6️⃣ Gender & Category Analysis

```sql
SELECT 
    category,
    gender,
    COUNT(*) AS total_trans
FROM sales_data
GROUP BY category, gender;
```

This compares purchasing activity between genders across different product categories.

---

## 7️⃣ Best-Selling Month by Year

A window function is used to identify the month with the highest average transaction value in each year.

```sql
RANK() OVER(
    PARTITION BY EXTRACT(YEAR FROM sale_date)
    ORDER BY AVG(total_sale) DESC
)
```

This demonstrates the use of:

- `GROUP BY`
- `AVG()`
- `EXTRACT()`
- `RANK()`
- Window Functions
- Subqueries

---

## 8️⃣ Top 5 Customers

```sql
SELECT 
    customer_id,
    SUM(total_sale) AS total_sales
FROM sales_data
GROUP BY customer_id
ORDER BY total_sales DESC
LIMIT 5;
```

This identifies the customers generating the highest total sales.

---

## 9️⃣ Unique Customers by Category

```sql
SELECT 
    category,
    COUNT(DISTINCT customer_id) AS unique_customer
FROM sales_data
GROUP BY category;
```

This measures the customer reach of each product category.

---

## 🔟 Sales by Time Shift

Transactions are divided into three shifts:

- 🌅 **Morning:** Before 12 PM
- ☀️ **Afternoon:** 12 PM – 5 PM
- 🌙 **Evening:** After 5 PM

```sql
CASE
    WHEN EXTRACT(HOUR FROM sale_time) < 12 
        THEN 'Morning'
    WHEN EXTRACT(HOUR FROM sale_time) BETWEEN 12 AND 17 
        THEN 'Afternoon'
    ELSE 'Evening'
END
```

This helps identify the periods when customers are most active.
